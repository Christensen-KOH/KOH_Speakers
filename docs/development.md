## Development

### Prerequisites

- Node.js 18+

### Dependencies

Install all dependencies

```bash
npm install
```

### Build

Start the Vite dev server with hot reload on http://localhost:8080

```bash
npm run dev
```

Type-check and build the game into `dist/` (assets from `data/` are copied alongside)

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```

### Tests

```bash
npm test
```

### Code quality

Code linting from terminal

```
npm run lint
```

It is highly advised to install the following plugins for you code editor:

- EditorConfig
- Prettier
- ESLint
